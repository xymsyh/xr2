# 开发说明

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `__main__.py` | 命令行参数、启动顺序、常驻与预渲染模式选择、音频设备释放 |
| `platform.py` | Windows 检查、输出编码、Tcl/Tk 修复、DPI 与进程代理环境 |
| `paths.py` | 项目相对路径、运行目录初始化，唯一的路径定义入口 |
| `config.py` | 首次配置生成、INI 读取与字段校验 |
| `runtime.py` | 启动后配置、消息队列与 OCR 忙碌状态 |
| `app.py` | 快捷键、剪贴板、任务取消、朗读与翻译调度 |
| `text.py` | 纯文本判断、代码检测、标识符拆分、语音选择 |
| `storage.py` | 语音与翻译缓存、学习记录读写 |
| `speech.py` | 缓存播放、edge-tts 合成、音频发送 |
| `translation.py` | 本地词典优先、在线翻译回退、结果与记录更新 |
| `dictionary.py` | 只读 SQLite 查询、词形与词条解析 |
| `ocr.py` | 本地 OCR 引擎懒加载与线程保护 |
| `ui.py` | Tk 浮窗和框选，截图通过回调交给调度器 |
| `cards.py` | 词典卡片和译文控件布局 |
| `prerender.py` | 剪贴板文本提取、受限并发、重试、日志与退出等待 |

入口先设置平台环境，再初始化配置；仅常驻模式打开音频设备和注册快捷键。预渲染不需要播放设备。导入核心模块不会自动生成配置、打开音频设备或注册全局快捷键。Tk 窗口通过队列接收译文，通过回调提交截图，避免界面与快捷键模块相互导入。

运行时可变内容放入 `runtime/`；只读词典继续放在 `data/`。不要在源码目录新增缓存或硬编码某台电脑的绝对路径。语音缓存沿用原有哈希规则，中文默认语音与英文 Clara 分开缓存。

## 检查

从根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q 启动.py xiaoxiao_reader tools
.\.venv\Scripts\python.exe 启动.py --help
```

测试覆盖配置、文本处理、词典、翻译分流、语音选择、音频发送协议、预渲染并发与重试，以及模块导入和异地启动路径。网络和硬件通过替身隔离；真实音频、按键、OCR、多屏和在线服务需要人工检查。

词典构建命令：

```powershell
.\.venv\Scripts\python.exe tools/构建本地词典.py [ECDICT_CSV]
```

省略 CSV 会下载固定版本；构建器验证 SHA-256 后写入 `data/dictionary.sqlite3`。重建前先关闭程序。数据来源与许可证见 [data/README.md](../data/README.md)。

预渲染与常驻程序共用磁盘缓存；避免同时运行写入缓存的多个实例。配置修改后需要重启，预渲染后重启常驻实例以加载新的译文缓存。
