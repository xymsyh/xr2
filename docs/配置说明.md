# 配置说明

配置位于 `config/配置.ini`。首次运行从无密钥的 `config/配置示例.ini` 创建，绝不覆盖已有文件。保存修改后重启程序。主使用流程见 [README](../README.md)。

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 按键映射 | 拖选朗读 / 选中朗读 / 截图朗读 | 默认 f8 / f9 / f10；单个键，三者不能重复 |
| 微软翻译API | 密钥 | 留空可朗读、查本地词典和使用译文缓存 |
| 微软翻译API | 区域 | 自己的资源区域，示例为 eastasia |
| 微软翻译API | 地址 | 兼容微软协议的 HTTP(S) 翻译地址，包含 /translate |
| 音频发送 | 启用 | true 或 false，默认 false |
| 音频发送 | 地址 | 启用时必须是完整 HTTP(S) 地址，发送实际播放的 MP3 |

不支持组合键和鼠标按钮名称；两个名称映射到同一扫描码也会被拒绝。按键不会被拦截，当前应用仍可能响应。

G502 等可编程鼠标用户可选用 f18 / f19 / f20；驱动输出与配置必须一致，拖选键需要保持按下/释放行为。

读取配置不依赖启动工作目录。不要将密钥放入示例或提交到 Git；本机配置已被忽略。旧配置不含 `[音频发送]` 时默认关闭该功能。
