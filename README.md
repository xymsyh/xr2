# 晓晓朗读

Windows 上的选中朗读工具：选中文字后按 **F9** 即可听原文；英文单词显示本地词典释义，英文短语和句子可显示中文翻译。无法复制的文字可以按 **F10** 截图识别。

中文及中英混合内容使用微软晓晓语音，纯英文使用 Clara。首次生成语音需要联网；OCR 和本地词典查询在本机完成。没有微软翻译密钥也能朗读、截图识别和查本地单词。

## 快速开始

需要 Windows 和 **64 位 Python 3.11**，安装 Python 时保留 Tcl/Tk 组件。将整个项目放在有写入权限的目录，在项目根目录打开 PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe 启动.py
```

也可以在依赖安装完成后双击根目录的 **启动.cmd**。不需要激活虚拟环境。没有 `py` 命令时，请使用 Python 3.11 的 `python` 命令创建环境。

首次启动会自动生成 `config/配置.ini`，已有配置不会被覆盖。保持程序运行，在记事本输入一段中文，选中后按 **F9** 测试。退出时，在程序控制台按 **Ctrl+C**。

## 默认按键与操作

| 按键 | 功能 | 使用方式 |
| --- | --- | --- |
| **F8** | 拖选朗读 | 鼠标指向文字，按住 F8；程序模拟双击并保持左键，可移动鼠标扩大选区，松开 F8 后朗读 |
| **F9** | 选中朗读 | 先用鼠标或键盘选中文字，再按 F9 朗读 |
| **F10** | 截图朗读 | 按 F10 后用鼠标左键框选文字，松开后识别并朗读；Esc 或右键取消 |

建议先熟悉“选中文字 → F9”，图片、扫描 PDF 或无法复制的字幕使用 F10。F8 的选词范围取决于目标应用的双击选择规则。

- 英文单词优先查询随项目提供的 ECDICT，显示音标、分词性释义、词形变化与标签；未收录时尝试在线翻译。
- 不含中文且未被判为代码的其他文本显示在线译文。中文内容和疑似代码只朗读；代码判断可能误判。
- 在线翻译前会将下划线变为空格，并拆分驼峰命名。朗读的是原文，中文释义不会自动朗读。
- 新操作会停止当前播放，并取消上一轮异步处理；已经发出的后台网络请求可能仍会完成。
- 浮窗可以拖动，位置会记住；双击关闭，约 99 秒后自动关闭。
- 重复文本优先使用语音和翻译缓存。音频合成完成后才播放，长文本首次朗读可能需要等待。

读取选区会模拟 **Ctrl+C**，并将文字留在剪贴板；OCR 识别结果也会复制到剪贴板。快捷键会继续传递给当前应用，若 F10 激活菜单或其他按键冲突，可修改配置。笔记本可能需要调整 Fn/Fn Lock。

## 设置

修改 `config/配置.ini`，保存后重启程序。

```ini
[按键映射]
拖选朗读 = f8
选中朗读 = f9
截图朗读 = f10
```

三个功能必须使用不同的单个按键，不支持 `ctrl+f9` 等组合键，也不直接接受鼠标按钮名称。

### 在线翻译

朗读不需要此密钥。需要翻译短语、句子或本地词典未收录的词时，在配置中填写自己的微软 Translator 资源信息：

```ini
[微软翻译API]
密钥 =
区域 = eastasia
地址 = https://api.cognitive.microsofttranslator.com/translate
```

密钥留空时仍可朗读、查本地词典以及使用已有译文缓存。区域应与自己的资源匹配，不能直接照抄示例；接口地址须兼容微软 Translator 文本翻译协议。目标语言是简体中文。服务额度和费用由自己的服务资源决定。

### 高级配置

**罗技 G502：** 推荐将三个鼠标键分别映射为 **F18 / F19 / F20**，并把配置中的拖选、选中、截图朗读同步改为 `f18 / f19 / f20`。拖选键需要保持真实的按下和松开行为，避免连发或点击即释放的宏；驱动无法输出这些键时，继续使用 F8/F9/F10。

**预渲染：** 推荐搭配 **Quicker 等触发器**，按“全选 → 复制 → 等待剪贴板更新 → 带参数启动”的顺序，执行：

```powershell
.\.venv\Scripts\python.exe 启动.py 预渲染
```

在触发器中，程序路径填本项目 `.venv\Scripts\python.exe` 的绝对路径；参数填写 `"D:\2026\22b 晓晓朗读新版\启动.py" 预渲染`。预渲染读取剪贴板，提取单词、词组、句子和完整行，生成缓存，不播放、不发送音频。日志写入 `runtime/logs/预渲染.md`；成功后 5 秒退出，失败时保留窗口供检查。建议先退出常驻程序再预渲染，完成后重新启动，以加载新的译文缓存并避免两个进程同时写缓存。

**音频发送：** 如需将实际朗读的 MP3 同时 POST 到音频服务，在 `[音频发送]` 中将 `启用` 改为 `true` 并填写自己的 HTTP(S) 地址。请求使用 `Content-Type: audio/mpeg` 和 `X-Filename: notice.mp3`；命中缓存也会发送，预渲染不会发送。默认关闭，发送失败不影响本地播放。

## 项目目录

```text
22b 晓晓朗读新版/
├── 启动.py                 # Python 入口，也支持“预渲染”参数
├── 启动.cmd                # 双击启动，优先使用本项目虚拟环境
├── xiaoxiao_reader/        # 程序源码：按职责拆分模块
├── config/                 # 配置示例与本机配置
├── data/                   # 随程序分发的只读词典及许可证
├── runtime/                # 程序运行产生的文件
│   ├── cache/              # 可删除的译文缓存和 audio/ 语音缓存
│   ├── data/               # 学习记录、浮窗位置
│   └── logs/               # 预渲染日志
├── docs/                   # 配置、迁移与开发说明
├── tests/                  # 自动化回归测试
├── tools/                  # 本地词典构建工具
├── .github/workflows/      # 自动检查
├── requirements.txt
├── README.md
└── LICENSE
```

所有文件路径以项目所在目录为准，从其他目录调用 `启动.py` 也不会把缓存写到工作目录。配置和运行数据与源码分开；缺失的运行目录会在启动时自动创建。

| 文件 | 用途 | 清理影响 |
| --- | --- | --- |
| `config/配置.ini` | 本机按键、API 密钥与音频发送设置 | 删除后按示例重新生成，需要重新配置 |
| `runtime/cache/audio/` | MP3 和语音索引 | 下次朗读重新合成，需要联网 |
| `runtime/cache/翻译缓存.json` | 已有译文 | 下次翻译重新查询服务 |
| `runtime/data/翻译记录.json` | 原文、释义、时间和次数 | 删除会失去本地学习记录 |
| `runtime/data/翻译窗口位置.json` | 浮窗位置 | 删除后恢复默认位置 |
| `runtime/logs/` | 预渲染结果 | 删除后失去对应日志 |

清理前退出程序；只清理缓存时删除 `runtime/cache/` 即可。缓存没有自动容量上限。换电脑时复制源码、`config/`、`data/` 和需要保留的 `runtime/` 数据，再重新创建虚拟环境。迁移说明见 [docs/迁移说明.md](docs/迁移说明.md)。

配置含个人密钥，缓存、记录和日志可能包含阅读内容；它们均已加入 Git 忽略规则，分享项目时请排除这些本机文件。OCR 图片只保存在内存，本地 OCR 不上传截图；识别后的文字仍可能进入在线朗读和翻译服务。控制台也会显示处理的文字。网络逻辑沿用直连方式，清除本进程中的常见代理环境变量，不修改系统代理。

## 常见问题

- **按键没反应：** 确认程序仍在运行，查看控制台的实际按键，先在记事本测试；检查 Fn 和目标应用的权限。若使用鼠标映射，检查驱动是否自动切换了配置文件。
- **选中文字没读出来：** 目标应用需支持 Ctrl+C，复制等待约 0.3 秒。先试手动选中后按 F9；不可复制的内容改用 F10。
- **没有声音：** 检查系统音量、输出设备和控制台错误。未缓存的内容需要联网合成语音。
- **朗读报 403，且请求含 `Sec-MS-GEC-Version=1-`：** 旧版 edge-tts 鉴权协议已不兼容。在项目目录执行 `.\.venv\Scripts\python.exe -m pip install --upgrade "edge-tts>=7.3.1,<8"`，完成后重启程序。
- **没有译文：** 中文或疑似代码会跳过翻译；单词未被本地收录时需要在线回退。检查密钥、区域、网络与服务额度。
- **OCR 慢或不准确：** 首次使用需初始化模型；圈选清晰、字号较大的文字，减少背景干扰。复杂排版、公式和手写识别效果有限。
- **缺少模块或 Tcl/Tk：** 安装依赖与运行程序须使用同一个 Python 环境；缺少 Tcl/Tk 时修复 Python 安装。
